# 🪄 4x 超分模型（Real-ESRGAN QNN）打包交付指南

> 适用对象：为 rmbg-offline App 制作/交付 **4x 超分模型**（QNN EPContext 或普通 ONNX）压缩包。
> 硬性依据：`SuperResEngine.kt`（加载/推理：自动识别 EPContext→QNN HTP / 普通 ONNX→CPU）、
> `ModelManager.importSuperResModelZip`（超分专用 zip 导入，存 `modelDir()/superres/`，与抠图模型隔离）。
> 本文**教你规范**：从零把一个 Real-ESRGAN 超分模型打包成 App 直接可用的 zip，并接入「按设备 CPU/SoC 型号自适应下载」。

---

## 1. 命名规范（三层：模型标识 → 文件 → 压缩包）

### 1.1 模型标识命名

```
qnn_realesrgan_<变体>_<平台>[_<soc编号>]_<htp版本>[_<sdk>]_<输入尺寸>_<精度>
```

| 段 | 规则 | 示例 |
|---|---|---|
| 前缀 | **必须 `qnn_`**（App 识别 QNN EPContext 硬标记） | `qnn_realesrgan_...` |
| 变体 | 超分模型名，小写语义化 | `anime6b`（Real-ESRGAN anime 6B） |
| 平台 | **必写**：`sm8550`/`8gen2`、`sm8650`/`8gen3`、`sm8750`/`8gen4`、`sm8350`/`8gen1`、`sm8450`/`8gen1+`、`sm8850`/`8gen5` | `sm8550` |
| soc 编号 | 可选，`soc<NN>`（QNN SDK soc_model） | `soc43` |
| htp 版本 | 可选，`v<NN>`（HTP 架构） | `v73` |
| sdk | 可选，`qairt250`（QNN 2.50） | `qairt250` |
| 输入尺寸 | **必写**：超分静态输入边长（QNN 通常固定） | `512` |
| 精度 | 可选，`fp32`（Real-ESRGAN 超分多为 FP32，HTP 用 burst 跑） | `fp32` |

✅ 规范例（SM8550 / soc43 / HTP v73 / QAIrt250 / 输入512 / FP32）：

```
qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32
```

> ⚠️ **平台段决定 App 型号自适应**（`qnnTargetSoc`/`autoPickDefaultModel` 解析）：
> - 含 `sm8550`/`8gen2` → 只在这台骁龙设备自动选中该包
> - 含 `sm8650`/`8gen3` → 只在 8 Gen 3 自动选中
> - App 启动时读 `Build.SOC_MODEL`，自动匹配对应 zip 下载；**用户无需手动选型号**。

### 1.2 文件命名（onnx 与 bin 必须同名同目录）

```
qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.onnx   ← EPContext 头（约几百字节）
qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.bin    ← context binary（30MB~100MB）
```

### 1.3 压缩包命名

```
qnn_realesrgan_<变体>_<平台>_<sdk>[_<输入尺寸>]_<精度>.zip
```

✅ 示例：`qnn_realesrgan_sm8550_qairt250_fp32.zip`

## 2. 压缩包内部结构（硬性要求）

```
qnn_realesrgan_sm8550_qairt250_fp32.zip
├── qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.onnx   ← 必须有 .onnx
└── qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.bin    ← 必须有配套 .bin
```

| 要求 | 说明 |
|---|---|
| 平铺 | 文件在 zip **根目录**，不要套子目录（App 解压只取 basename） |
| 无隐藏文件 | 不要 `__MACOSX`、`.DS_Store` |
| 仅 onnx+bin | 禁止多个 .bin（App 用精确→包含→唯一兜底匹配） |
| 压缩法 | **推荐 `store`（不压缩）**：bin 已是大文件，压缩不省空间还拖慢部署 |

---

## 3. 数据内容要求（超分特有）

### 3.1 BIN（QNN context binary）

| 项 | 要求 |
|---|---|
| 格式 | `qnn-context-binary-generator` 直接输出 **context binary v2**（头 4 字节 `00 00 00 02`） |
| ❌ 排除 | POSIX tar 权重包（偏移 257 处 `ustar`） |
| SDK | **QNN 2.50**（App runtime `qnn-runtime:2.50.0`） |
| 输入 shape | **静态 512×512**（Real-ESRGAN QNN 典型）→ 输出 2048×2048（4x） |
| 输入/输出名 | App **动态读取**（不写死）：QNN 超分常见 `image_1` → `output_0` |

### 3.2 ONNX（App 可自动修复，导出即合规最稳）

| 项 | 要求 |
|---|---|
| `ep_cache_context` | = **bin 纯文件名**（无 `/`、无目录）；绝对路径 App 会改写但导出即合规最稳 |
| `embed_mode` | `0`（外部引用 bin） |
| `source` | `QNN`（QNN EPContext 标记） |

## 4. 校验清单（交付前自查）

```
□ 文件名符合 qnn_realesrgan_<变体>_<平台>[_<soc>_<htp>_<sdk>_<输入>_<精度>] 规范
□ onnx 与 bin 同名同目录
□ zip 内文件平铺根目录、无隐藏文件
□ onnx 内 ep_cache_context = bin 纯文件名（无 /）
□ bin 头 4 字节 = 00 00 00 02（context binary v2，非 tar）
□ bin 由 QNN 2.50 编译
□ 平台段与 soc_model 一致（SM8550= soc43 / v73）
□ 输入 512×512 → 输出 2048×2048（4x）
```

## 5. 制作指南（6 步产出合规 zip）

### 5.1 准备编译环境

| 项 | 要求 |
|---|---|
| QNN SDK | **2.50**（`ep_sdk_version` = `v2.50.0.260828221209`） |
| 目标设备 | 确认 soc_model + HTP 版本（SM8550 = soc43 / HTP v73） |
| 模型 | Real-ESRGAN anime6B 导出 ONNX（输入 512×512，输出 2048×2048） |

### 5.2 编译 context binary（在 bin 输出目录内执行）

```bash
cd <bin输出目录>            # ← 先 cd，保证导出引用为纯文件名
qnn-context-binary-generator \
  --model <模型.onnx> \
  --backend htp \
  --binary_file <输出>.bin \
  --soc_model 43 \          # SM8550=soc43；其他型号按对应值
  --htp_socs 73 \           # HTP v73（SM8550）
  --debug --saver 1
```

> ⚠️ 不要在命令行写输出路径（会变成绝对路径引用，App 加载报 `ORT_INVALID_GRAPH`）。

### 5.3 规范化命名

```bash
mv <输出.onnx> qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.onnx
mv <输出.bin>  qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.bin
```

**bin 名必须与 onnx 内 `ep_cache_context` 引用一致。**

### 5.4 校验 / 修正 ep_cache_context

```bash
python3 - <<'EOF'
import onnx
m = onnx.load("qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.onnx")
for node in m.graph.node:
    if node.op_type == "EPContext":
        for a in node.attribute:
            if a.name == "ep_cache_context":
                print("引用:", a.s.decode())
                ok = b"/" not in a.s and b"\\" not in a.s
                print("合规:", "✅" if ok else "❌")
                if not ok:
                    a.s = b"qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.bin"
                    print("已改写:", a.s.decode())
onnx.save(m, "qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.onnx")
EOF
```

### 5.5 打包 zip（平铺根目录 + store）

```bash
zip -0 -j qnn_realesrgan_sm8550_qairt250_fp32.zip \
  qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.onnx \
  qnn_realesrgan_anime6b_sm8550_soc43_v73_qairt250_512_fp32.bin
```

- `-0`：store 不压缩；`-j`：强制平铺根目录
- 包内只允许 onnx + bin 两个文件

### 5.6 交付前校验

```bash
ZIP=qnn_realesrgan_sm8550_qairt250_fp32.zip
unzip -l "$ZIP"                  # ① 结构：应只有 onnx+bin，平铺
TMP=$(mktemp -d); unzip -o -q "$ZIP" -d "$TMP"; cd "$TMP"
head -c 4 *.bin | od -A x -t x1z  # ② bin 头 4 字节 = 00 00 00 02
dd if=*.bin bs=1 skip=257 count=5 2>/dev/null | od -c  # ③ 无 ustar（非 tar）
python3 -c "import onnx;m=onnx.load('$(ls *.onnx)');print([a.s for n in m.graph.node if n.op_type=='EPContext' for a in n.attribute if a.name=='ep_cache_context'])"
```

## 6. 双路径支持（QNN 与 CPU 都行）

| 模型类型 | 加载方式 | 加速 |
|---|---|---|
| **QNN EPContext**（onnx+bin zip） | `SuperResEngine` 自动检测 EPContext → 注册 QNN EP | HTP DSP（比 CPU 快 5-10 倍） |
| **普通 ONNX**（单 .onnx，无 bin） | 自动识别无 EPContext → 纯 CPU | CPU |

> App 导入超分模型时自动判断：zip 含 bin + onnx 内 `ep_cache_context` → 当 QNN；否则当 CPU。
> **推荐 QNN 超分**（静态 512→2048，HTP burst 模式，30s CPU 可压到几秒）。

## 7. 型号自适应下载（多 SoC 变体）

仓库按**多平台变体**组织，App 启动自动匹配设备型号：

```
qnn/qnn_realesrgan_sm8350_qairt250_fp32.zip   ← 8 Gen 1
qnn/qnn_realesrgan_sm8450_qairt250_fp32.zip   ← 8 Gen 1+
qnn/qnn_realesrgan_sm8550_qairt250_fp32.zip   ← 8 Gen 2
qnn/qnn_realesrgan_sm8650_qairt250_fp32.zip   ← 8 Gen 3
qnn/qnn_realesrgan_sm8750_qairt250_fp32.zip   ← 8 Gen 4
qnn/qnn_realesrgan_sm8850_qairt250_fp32.zip   ← 8 Gen 5
```

App 端 `BuiltinModel` 配置每个变体（`hfZip` 指向对应 zip + `qnnTargetSoc` 平台段），
启动时 `autoPickDefaultModel` 按 `Build.SOC_MODEL` 选中匹配的 zip 下载。
